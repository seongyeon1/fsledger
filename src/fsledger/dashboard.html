스캔별 변경

스냅샷 하나가 스캔 한 번입니다. 첫 스캔(전체 등록)은 빼고 그렸습니다.

숫자 표로 보기

용량이 큰 폴더

추적 루트 바로 아래 폴더 기준입니다. node_modules 같은 재생성 폴더 크기도 포함됩니다.

최근 변경

CDC 방식으로 쌓인 이벤트입니다. 특정 파일의 전체 이력은 fsledger history <경로> 로 봅니다.

중복 파일

내용 해시가 같은 파일 묶음입니다. 맨 위가 남길 원본이고, 나머지는 정리 후보에 들어갑니다. 원본 선택 기준: Downloads 밖 → 복사본 이름이 아닌 쪽 → 경로가 짧은 쪽.

규칙별 합계

safe 는 OS나 도구가 다시 만드는 것, review 는 한 번 보고 판단할 것입니다.

폴더 정리 계획

      
정리 루트 최상위의 낱개 파일만 카테고리 폴더로 옮깁니다. 폴더, 숨김 파일,
        최근 이틀 안에 수정한 파일, git 저장소는 건드리지 않습니다. 모든 이동은 되돌릴 수 있습니다.

      

      
fsledger organize            # 계획만 보기
fsledger organize --apply    # 실행
fsledger undo                # 마지막 배치 되돌리기
